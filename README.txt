LUMA BOTANICS — GITHUB PAGES WEBSITE
=====================================

WHAT'S INCLUDED
- index.html       Home page
- products.html    Product collection with category filters
- about.html       Brand story, mission and values
- contact.html     Contact demo form and newsletter demo
- style.css        Responsive styling for all four pages
- script.js        Mobile menu, filters, validation and GA4 event examples

THE WEBSITE THEME
Luma Botanics is a fictional, premium everyday skincare concept brand.
The sample products, prices, contact details and testimonials are illustrative.
The forms are demonstrations only: they do not send messages or subscribe anyone.

QUICK START
1. Extract the ZIP file.
2. Open index.html in a browser to preview (some browser restrictions may apply to local files).
3. Upload all six website files to the ROOT of your GitHub repository.
4. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

GOOGLE ANALYTICS 4
The four HTML files contain a GA4 placeholder: G-XXXXXXXXXX.
Replace every occurrence in all four HTML files with your actual GA4 Measurement ID.
Page views are measured through GA4's normal page_view tracking.
Product buttons send select_item.
Contact and newsletter demo forms send demo_form_submit after browser validation.
No generate_lead or sign_up events are sent because these forms do not complete a real lead or subscription.

IMPORTANT
- Images and Google Fonts are loaded from public third-party URLs, so internet access is required.
- This is a static website. No cart, checkout, form backend, email service or mailing list is connected.
- Do not use a real personal email address in a public student repository unless you intend it to be public.
